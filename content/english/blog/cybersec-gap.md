## The Gap
You know the cybersecurity market, especially if you're reading this blog. From what I understand there are 2 models:
* SaaS. This is constant but misses vulns all the time.
* Audits. Not every exploit is conveniently aligned with the Quarterly Audit, but these are reliable
I have a new model to present and I call it Constant Audits:

You start with an initial audit. This is important because this whole model operates with one assumption:

The previous state was secure.

This initial audit makes sure that that assumption holds true.

Then, you look at diffs
Only the diffs, git or otherwise, are checked from then on. This significantly reduces the workload.

Of course, this relies on the fundamental assumption I made earlier. This is why it is so important in this model to have an initial audit.
